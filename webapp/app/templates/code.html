Everything on this site — the Explore timelines, the Data downloads, and the sibling MCP server — is produced by the FastAPI + Jinja + (vendored) Plotly app and the canonical query module below. The snippets here are verbatim from the running source.

Run it, get identical output. 1 · The public-only chokepoint

One module touches the corpus. It imports app.config first (which forces METHODEX_PUBLIC_ONLY=1 before methodex_mcp loads), then asserts every loaded document is public domain — the import fails closed otherwise.

webapp/app/services/methodex_service.py
{% filter forceescape %}{% raw %}from app import config as C  # import-for-side-effect: forces public-only

if str(C.SRC_DIR) not in sys.path:
    sys.path.insert(0, str(C.SRC_DIR))

import methodex_mcp as M

# Hard assertion: the bridge must be in public-only mode.
assert M.PUBLIC_ONLY, (
    "methodex_mcp loaded WITHOUT public-only mode — refusing to serve. "
    "app.config must be imported before methodex_mcp."
)
assert all(
    (d.get("provenance") or {}).get("license") == C.PUBLIC_DOMAIN_LICENSE
    for d in M.DOCSL
), "Non-public document found in the loaded store — public carve breached."{% endraw %}{% endfilter %}

3 · The downloads (correct content-types)

The Data page serves three datasets as CSV. Each carries its true media type — the known "CSV-served-as-JSON" failure is avoided by attaching the content-type at export time.

webapp/app/services/download_service.py
{% filter forceescape %}{% raw %}_CSV = "text/csv; charset=utf-8"

def export_dataset(name: str, fmt: str, statistic_id: str | None = None):
    """Export a named public dataset as csv. Raises KeyError/ValueError."""
    if name not in _FRAMES:
        raise KeyError(f"unknown dataset '{name}' (have: {sorted(_FRAMES)})")
    if fmt != "csv":
        raise ValueError(f"unsupported format '{fmt}' (csv)")

    builder = _FRAMES[name]
    df = builder(statistic_id) if name in ("statistics", "revision_events") else builder()

    suffix = f"_{statistic_id}" if statistic_id else ""
    raw = df.to_csv(index=False).encode("utf-8")
    return raw, _CSV, f"methodex_{name}{suffix}.csv"{% endraw %}{% endfilter %}

4 · The revision timeline (vendored Plotly, offline)

Each statistic's timeline is built server-side into a Plotly figure dict and hydrated in-page with the vendored Plotly build — no CDN, no runtime fetch. Every point is a real, cited revision event.

webapp/app/services/methodex_service.py
{% filter forceescape %}{% raw %}import plotly.graph_objects as go

dated = [e for e in events if e.get("effective_year")]
types = sorted({e["type"] for e in dated})

fig = go.Figure()
for t in types:
    pts = [e for e in dated if e["type"] == t]
    fig.add_trace(go.Scatter(
        x=[e["effective_year"] for e in pts],
        y=[t for _ in pts], mode="markers", name=t,
        customdata=[[e["event_id"], (e.get("description") or "")[:240],
                     (e.get("citation") or {}).get("document", ""),
                     "verified" if e.get("verified") else "unverified"] for e in pts],
        hovertemplate="%{x} · " + t + "
%{customdata[1]}"
                      "
src: %{customdata[2]}
(%{customdata[3]})",
    ))
return {"figure": fig.to_plotly_json(), "events": events}{% endraw %}{% endfilter %}

5 · The landing chart API

The default chart on the home page reads this endpoint, which rolls up real public events live from the store (so it always matches the rest of the site).

webapp/app/routers/api.py
{% filter forceescape %}{% raw %}@router.get("/coverage")
def coverage() -> JSONResponse:
    stats = S.statistics_with_events()
    by_family: dict[str, int] = {}
    for s in stats:
        by_family[s["family"]] = by_family.get(s["family"], 0) + s["n_events"]
    top = sorted(stats, key=lambda s: (-s["n_events"], s["name"]))[:15]
    return JSONResponse({
        "top_statistics": [{"name": s["name"], "statistic_id": s["statistic_id"],
                            "family": s["family"], "n_events": s["n_events"]} for s in top],
        "by_family": sorted(({"family": f, "events": n} for f, n in by_family.items()),
                            key=lambda x: (-x["events"], x["family"])),
        "n_total_events": sum(s["n_events"] for s in stats),
        "n_statistics": len(stats),
    }){% endraw %}{% endfilter %}

6 · Reproduce the coverage chart yourself (R + Python)

Everything above is the app's own plumbing. To check the numbers without running the app, read the published revision-events CSV directly and roll it up — the same count behind the landing coverage chart. Switch between R and Python with the toggle; point events_url at the downloaded file or the live URL.

events per statistic family, from the public CSV 
{% filter forceescape %}{% raw %}# Methodology revision events per statistic family, from the public CSV.
# Each row is one dated, cited methodology change (the site's unit of analysis).

# DATA:   point events_url at the published revision-events download.
# CHANGE: the grouping column (e.g. `type` instead of `family`).

events_url <- "https://methodex.fyi/download/revision_events.csv"

ev <- read.csv(events_url, stringsAsFactors = FALSE)

# count events per statistic family, most-revised first
by_family <- as.data.frame(table(family = ev$family), stringsAsFactors = FALSE)
by_family <- by_family[order(-by_family$Freq), ]
names(by_family)[2] <- "n_events"

cat(sprintf("total cited revision events: %d\n", nrow(ev)))
print(head(by_family, 10), row.names = FALSE){% endraw %}{% endfilter %}
