Methodology & provenance

Every document, revision event, and statistic served here is transcribed from a public-domain US-federal-government source and carries a governing citation — nothing is fabricated. This page is the Data Provenance Record (DPR): sources · construction · units · coverage · limits · last-updated · citations.

Data Provenance Record

Sources
US-federal-government statistical manuals, handbooks, and releases — BEA NIPA handbooks, BLS CPI/CES handbooks, and sibling US-Gov works, public domain under 17 U.S.C. §105 and hence servable verbatim. Revision events are cited methodology changes extracted from those governing documents, each carrying a governing-document MD5 + page citation. Data-vintage links are ALFRED/FRED real-time series pointers (St. Louis Fed) cross-linking a methodology to the data vintage in force at a date.
Construction
The corpus was collected, transcribed, structured, and license-classified in the Methodex campaign (Technical/campaign/), then carved to the public-domain layer by a license-classification step. The hosted app forces METHODEX_PUBLIC_ONLY=1 at import time, so the in-memory stores are physically filtered to public-domain documents and the events, measures, and statistics derived from them. The served layer is {{ status.documents }} documents, {{ status.events }} cited revision events, {{ status.statistic_entities }} statistic entities catalogued ({{ status.statistics_with_events }} with served revision histories), and {{ status.measures }} published measures/tables. The same store powers the Explore timelines, the Data downloads, and the sibling MCP server — see Code.
Units & coverage
Coverage is organised by statistic family. Families present in the served layer (with the number of statistics that carry cited revision histories): {% for f in families %}{{ f.family }} ({{ f.n }}){% if not loop.last %}, {% endif %}{% endfor %}. Each statistic is keyed by a canonical id (e.g. US.BLS.CPI_U); revision events are placed on a per-statistic effective-year axis. The unit of every figure on the site is a methodology event (a dated, cited change), not a data value — Methodex documents how statistics were measured, it does not republish the series themselves.
Limits
  • Public-domain layer only. The full Methodex research corpus also contains in-copyright international / academic / unknown-producer material; none of it is loaded or served here. In-copyright sources are digest-only in the research corpus and are never served verbatim by this site.
  • Counts are a strict subset. Public-only filtering drops events whose governing document is non-public, so the hosted event/statistic counts ({{ status.events }} / {{ status.statistic_entities }}) are smaller than the full-corpus totals.
  • Verification is partial. {{ status.verified_events }} events are adversarially verified and flagged inline; the rest are transcribed-with-citation but not independently re-verified.
  • Vintage links are pointers. get_vintage_data returns ALFRED/FRED URLs only — it never fetches data over the network at runtime (keeps the deploy offline-safe).
  • Some bindings are heuristic. _doc_matches_stat uses MVP title/producer heuristics for a few statistic↔document links; canonical statistic_ids bindings are authoritative where present.
Downloads
The three served datasets — statistics, revision_events, and documents — are downloadable as CSV from the Data page (and bundled in bundle.zip with a README). The unit is a methodology event, not a data series, so the public layer is tabular CSV; the machine-readable coverage manifest (metadata, not a dataset download) is at /metadata/manifest.json. No JSON dataset downloads are offered as the user-facing data format.
Refresh cadence
On-source-release (manual). The governing documents are US-federal statistical manuals and handbooks (BEA NIPA Handbook, BLS Handbook of Methods, agency release notes) that revise on irregular agency schedules; new revision events are transcribed-with-citation as those sources publish, in the Methodex campaign, then re-carved to the public-only layer by a license-classification step and redeployed. There is no fixed automated cadence — the corpus grows as governing documents are released and processed.
Citations
Legal basis: 17 U.S.C. §105 (works of the U.S. federal government are not subject to copyright). Primary governing sources include the BEA NIPA Handbook, the BLS Handbook of Methods (CPI, CES, and sibling chapters), and the agency release notes from which each revision event is cited. Every served event names its governing document and page; the full set is downloadable on the Data page.
